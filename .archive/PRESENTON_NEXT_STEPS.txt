STEP 1: Set Environment Variables
──────────────────────────────────

Run these commands to make the configuration permanent:

cd /home/ubuntu/AGENT/backend
cat >> .env << 'EOF'

# Presenton AWS ECS Configuration (Added Jan 10, 2026)
PRESENTON_API_URL=http://172.31.10.166:80
PRESENTON_REQUIRE_AUTH=false
PRESENTON_MAX_SLIDES=12
EOF


STEP 2: Restart Backend
────────────────────────

Choose one:

A) If using systemd:
   sudo systemctl restart hrsp-backend

B) If running manually, export and restart:
   export PRESENTON_API_URL=http://172.31.10.166:80
   export PRESENTON_REQUIRE_AUTH=false
   export PRESENTON_MAX_SLIDES=12
   cd /home/ubuntu/AGENT/backend
   source venv/bin/activate
   uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload


STEP 3: Test PowerPoint Generation
───────────────────────────────────

1. Open your application in browser
2. Login
3. Send message: "Create a presentation about cloud computing"
4. Click: "Yes, generate PowerPoint"
5. Wait for generation (~15-20 seconds)
6. Download the PowerPoint file
